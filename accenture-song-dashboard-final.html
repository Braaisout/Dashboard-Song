How to run a prototype sprint
Using IKEA Skapa (open now)
Skapa components are on npm and fully public. Install them, apply the tokens, and you're building a prototype that looks 100% like IKEA's product.
npm install @ingka/button @ingka/text npx ux-ingka spark "circular recommender"
Using B01LER for any other client
Fork Song's own open-source B01LER design system, apply the client's brand tokens (colours, typography, spacing), and prototype quickly without needing access to the client's own DS.
git clone github.com/deven-org/boiler tokens/brand.json → swap colors + fonts

Gated sources — request access

Meta Graph API and LinkedIn Marketing API require app review and client-granted access. Useful for post performance data with explicit client consent.
How to connect safely — step by step
1
Start with open sources only — no credentials needed
For IKEA Skapa, B01LER, and NL Design System: clone the GitHub repo or install from npm. No API keys, no client permission required. This is your prototype sandbox.
npm install @ingka/button @ingka/text @ingka/focus
2
Use Claude Code to wire agents to these sources
Claude Code (claude.ai/code) can read GitHub repos, fetch npm package docs, and generate prototype UIs using the real token values — all locally on your machine.
claude "read the IKEA Skapa tokens and build a circular product card"
3
For gated sources: read-only API keys only, stored in .env
Never paste client API keys into Claude chat directly. Store them in a local .env file and reference them in Claude Code. The key never leaves your machine.
FIGMA_TOKEN=xxx → .env → gitignore this file always
4
No client PII or confidential data in prompts
When asking Claude to help with client work: use anonymised data, reference design tokens (not client files), and confirm with Accenture's data handling policy before using any real client assets in AI tools.
5
Internal use only until client-approved
Any prototype using client brand tokens or assets is for internal ideation only — do not publish or share outside Accenture without explicit client sign-off. Use Netlify/GitHub with access controls.
